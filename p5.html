In semantic html, each element has a specific meaning and purpose. It helps search engines and assistive technologies understand the structure and content of a web page, making it more accessible and user-friendly.

In nav tag we can use ul, li, a, button, form, input, select, option and many more.

In header tag we can use h1-h6 to set heading of the page

Section content goes here. in main tag we can use section, article, aside, h1-h6, p, ul, li, a, img, video, audio, form, input, button, label, table, tr, td, th, caption, figure, figcaption, details, summary, mark, time, progress, meter and many more.

Article

Article content goes here. In article tag we use a specific piece of content that can stand alone and be distributed independently. It can contain headings, paragraphs, images, videos, and other elements.

In aside tag we can use it to add supplementary content that is not directly related to the main content.

Footer content

In footer tag we can use it to provide information about the website, such as copyright information, contact details, and links to related resources.
